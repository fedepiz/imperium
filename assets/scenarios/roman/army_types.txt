# The types of army towns recruit. Each has an id, a snake_case word the other files name it by, and a name. Then:
#   scope: Local, tied to a home region, the one it is recruited in; or Global, with none
#   men, proficiency 0..100, foraging 0..100, mobility 1..4: at full strength. Recruited, it starts weak and reinforces
#   recruit_requires: the features its town must have, written as declared (Horses, Drill, Court)
#   recruit_coin: paid on recruiting
#   upkeep_coin, upkeep_labour: per turn, coin out of the treasury and labour out of its home town
#   description: what it is, shown when it is hovered
# Every key is given: none has a default. Which cultures recruit which types is in cultures.txt.
